# FPT218 高还原克隆经验记录

## 项目目标
- 基于 `https://www.fptindustrie.com/zhs/` 做中文站高还原静态克隆。
- 先完成首页，再逐步补齐二级页面，并保证导航可点击、页面可互相跳转。

## 本次有效做法
1. 先做“结构还原”，再做“像素打磨”。
2. 统一抽取 Header / Footer 样式和交互，避免每页重复修。
3. 保留官网资源链接（logo、图标、图片）以提高还原速度。
4. 对导航做本地化重写（`./fpt218-*.html`），避免跳回官网。
5. 每完成 1-2 个页面就本地预览，及时修 hover、active、可点击区域问题。

## 已验证的交互要点
- 顶部导航文字 hover：黄色文字填充效果（而不是按钮背景填充）。
- 主导航 active 态与当前页面一致。
- 首页及二级页顶部导航支持本地跳转。
- Footer 社媒图标、联系方式、语言区可展示和点击。

## 本次踩坑与修复
1. **问题：HTML 缺失交互**
   - 原因：早期导出偏“切片”，可点击结构不完整。
   - 修复：改为语义化 HTML + 明确 `<a>` 覆盖层，不依赖纯位图。

2. **问题：导航跳官网**
   - 原因：直接沿用官网 URL。
   - 修复：统一替换为本地二级页地址，保留官网深层链接仅用于内容详情。

3. **问题：批量替换误伤 URL**
   - 原因：通配替换过宽导致链接拼接异常。
   - 修复：改为精确替换并增加 `rg` 校验步骤。

## 推荐流程（下次可复用）
1. 抓取页面结构与资源。
2. 先做首页骨架 + 导航交互 + Footer。
3. 按导航顺序增量做二级页（企业/产品/技术/行业/服务/联系方式）。
4. 每页完成后做三档检查：
   - 视觉：与目标页层级、间距、颜色一致
   - 交互：hover / active / clickable
   - 响应式：320 / 768 / 1440 不溢出
5. 最后统一回归：首页是否能进入所有二级页，二级页是否能返回首页和互跳。

## 后续可继续优化
- 为服务页子栏目（项目经理/培训课程/物流中心等）继续补齐本地页。
- 联系方式页面接入真实地图 iframe（当前为占位方案可升级）。
- 抽出公共 CSS 到单独文件，降低多页维护成本。
